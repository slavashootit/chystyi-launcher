# Чистий (Chystyi Launcher) — власний мінімалістичний ланчер для S25 Ultra

Нативний Kotlin без AndroidX і сторонніх бібліотек (`minSdk 30`, `targetSdk 35`).
Прозорий поверх системних шпалер із градієнтним скрімом, нуль інтернет-дозволів, миттєвий пошук із автозапуском та розкладкою `ЙЦУКЕН ↔ QWERTY`.
Ставиться файлом APK (`~/Downloads/Chystyi-Launcher.apk`). Почато 2026-10-30.

## Що вміє
- **Головний екран під одну руку (S25 Ultra):**
  - 5–8 головних програм чистим текстовим списком у нижній половині екрана без кольорових іконок.
  - Прозорий фон поверх системних шпалер (`windowShowWallpaper = true`) із 4 режимами затемнення: `Легке (30%)`, `Середнє (50%)`, `Глибоке (75%)`, `Чистий AMOLED (#000000)`.
  - Вирівнювання тексту: `Ліворуч`, `По центру` або `Праворуч (під праву руку)`.
- **Жести на головному екрані:**
  - **Свайп угору будь-де** → плавно відсуває головний екран углиб і відкриває меню всіх програм з миттєвою клавіатурою.
  - **Свайп униз будь-де** → розгортає системну шторку сповіщень (`StatusBarManager.expandNotificationsPanel`).
  - **Свайп вправо (→)** → запускає призначену програму (за замовчуванням «Стан» або Телефон) з живим індикатором і тактильним відгуком.
  - **Свайп вліво (←)** → запускає призначену програму (за замовчуванням Камера).
  - **Тап на годинник** → Будильник / Годинник; **тап на дату** → Календар.
  - **Довгий тап по вільному місцю (або на годинник)** → Налаштування ланчера.
- **Меню всіх програм і розумний пошук:**
  - Пошук знаходить програми навіть без перемикання мови клавіатури (`ЙЦУКЕН ↔ QWERTY` та українська транслітерація).
  - Автозапуск, коли при наборі залишається рівно 1 збіг (можна вимкнути в налаштуваннях); клавіша `Enter`/`Go` завжди запускає перший збіг (`↵`).
  - Бічна алфавітна смужка (`А..Я`, `A..Z`) з тактильним відгуком для швидкого переходу.
  - Довгий тап на програмі → перейменувати, приховати системне сміття зі списку, додати/прибрати з головного, призначити на свайп.

## Збірка
```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
cp app/build/outputs/apk/release/app-release.apk ~/Downloads/Chystyi-Launcher.apk
```
Перед кожним оновленням піднімати `versionCode` в `app/build.gradle.kts`.

## Ключ підпису — НЕ ВТРАТИТИ
`release.keystore` + `keystore.properties` у корені `vibecode/launcher`. Оновлення поверх встановленого ланчера працює лише з тим самим ключем підпису.
